# Gaia Data Exploration Project: gaia-exploration

This repository contains the code and report for a data exploration project focused on Gaia space observation data. This project was part of the 32130 Fundamentals in Data Analytics course at the University of Technology Sydney (UTS) in Fall 2024.

## Contents

- Code for data visualization, exploration, and preprocessing.
- Final report detailing the project, methodology, and results.
- Excel workbook with individual spreadsheets for each task.

## Introduction

This is the final report on a data exploration project that aims to analyze and preprocess space data related to the Gaia project. The report is structured as follows:

1. **Introduction**: An overview of the project and its goals.
2. **Initial Data Exploration**: Identifying attribute types and summarizing their properties.
3. **Multiple Attribute Relationships**: Exploring relationships, outliers, clusters, and interesting attributes.
4. **Data Preprocessing**: Applying binning, normalization, discretization, and binarization techniques.
5. **Summary of Findings**: Highlighting important characteristics, distributions, clusters, and associations for further investigation.
